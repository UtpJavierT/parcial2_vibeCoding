// Inicio / ¿Qué es?

Programar con lenguaje natural.

El Vibe Coding es una forma de crear software en la que la persona describe lo que quiere y un modelo de inteligencia artificial se encarga de escribir la mayor parte del código.

// El origen

Un término nacido en 2025.

El nombre lo popularizó Andrej Karpathy, cofundador de OpenAI y exdirector de IA en Tesla, en febrero de 2025. Lo describió como dejarse llevar por la “vibra”: pedir cambios, aceptar lo que sugiere la IA y casi olvidarse de que el código existe.

La idea se extendió tan rápido que el diccionario Collins eligió vibe coding como su palabra del año 2025.

// El proceso

¿Cómo funciona?

El trabajo se vuelve un ciclo corto de pedir, probar y ajustar.

  1. Describir la idea. Se escribe un prompt claro: qué se quiere construir, para quién y con qué tecnologías.
  2. La IA genera el código. El asistente crea archivos, funciones o páginas completas en segundos.
  3. Probar el resultado. Se ejecuta la aplicación y se revisa si hace lo que se pidió.
  4. Pedir cambios. Si algo falla, se describe el error o la mejora y la IA lo corrige.
  5. Revisar y entender. Antes de publicar, se lee el código para asegurar que es correcto y seguro.

// Comparación

Tradicional vs. Vibe Coding

AspectoProgramación tradicionalVibe Coding
¿Quién escribe el código?El programador, línea por línea.La IA, guiada por instrucciones.
Habilidad principalDominar la sintaxis del lenguaje.Explicar bien el problema.
VelocidadMás lenta al iniciar.Prototipos en minutos.
Control del códigoTotal.Depende de cuánto se revise.

Idea clave: la IA no reemplaza los fundamentos. Saber HTML, CSS y lógica de programación es lo que permite pedir mejor y detectar cuando la IA se equivoca.
